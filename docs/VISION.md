# Ovll

**AI와 함께한 작업을, 다시 사용할 수 있는 가치로.**

AI와 함께 만들어 낸 결과가 다음 작업에서도 이어진다면 어떨까요?

매번 같은 지시를 반복하고, 자료를 다시 정리하고, 잘 작동했던 절차를 처음부터 재구성하는 대신. Ovll(오블)은 대화 속에서 시작된 작업을 이해하고, 조정하고, 재사용할 수 있는 AI 작업 공간을 지향합니다.

## 대화에서 시작하는 작업

복잡한 흐름을 먼저 설계할 필요는 없습니다. 원하는 일을 자연어로 전달하면, 간단한 요청은 대화로 해결하고 여러 단계가 필요한 작업은 목적에 맞게 구성하는 경험을 추구합니다.

사용자가 도구의 사용법보다 **하고 싶은 일 자체에 집중할 수 있도록** 만드는 것이 출발점입니다.

## 눈으로 이해하고, 직접 조정하는 캔버스

작업이 복잡해져도 흐름을 놓치지 않도록. 캔버스는 스킬과 작업의 연결 관계, 진행 상태, 결과를 살펴보고 필요한 부분에 개입할 수 있는 공간입니다.

AI가 구성한 작업을 사용자가 수정하고, 그 변경을 바탕으로 AI와 다시 작업할 수 있습니다. **시각화는 단순한 전시가 아니라 사람과 AI가 작업을 함께 다루는 방식**입니다.

## 한 번의 작업을 다음 작업의 출발점으로

유용한 작업은 일회성 대화에 머물지 않아야 합니다.

Ovll은 작업을 재사용 가능한 스킬로 정의하고, 반복할 가치가 있는 절차를 함수로 발전시키는 경험을 지향합니다. 다음번에는 이전 과정을 전부 다시 설명하는 대신, 새로운 자료와 달라진 조건에 집중할 수 있도록.

**처음의 작업이 쌓일수록, 다음 작업은 더 수월해지는 것.** 이것이 Ovll이 만들고자 하는 가치입니다.

---

Ovll은 AI를 대체하려는 기술이 아닙니다. AI의 능력을 사용자의 목적에 연결하고, 그 과정에서 생긴 작업과 결과를 더 쉽게 이해하고 활용할 수 있도록 돕는 플랫폼입니다.

모든 판단을 AI에 맡기는 대신, 필요할 때는 사용자가 작업의 방향을 확인하고 조정할 수 있어야 합니다.

**대화로 시작해, 이해하고, 다시 활용하는 AI 작업 공간. Ovll.**
