# Ovll

**AI와 함께한 작업, 다음에도 쓸 수 있게.**

AI와 꽤 괜찮은 결과를 만들었는데, 다음번에는 또 처음부터 설명해야 한다면?

자료를 다시 건네고, 지시를 다시 쓰고, 잘됐던 과정을 기억해서 반복하는 일. AI가 일을 도와줘도 그 사이의 번거로움은 여전히 사람의 몫일 때가 많아.

**Ovll(오블)은 대화에서 시작한 작업을 눈으로 이해하고, 직접 조정하고, 다시 사용할 수 있도록 만드는 AI 작업 공간이야.**

## 말로 시작해

처음부터 복잡한 자동화 흐름을 설계할 필요는 없어. 하고 싶은 일을 자연스럽게 이야기하는 데서 시작해. 간단한 질문은 대화로, 여러 단계가 필요한 일은 작업으로 이어지는 경험을 지향해.

## 캔버스에서 함께 다듬어

AI가 무엇을 하려는지, 어떤 작업이 연결되어 있는지, 실제로 어디까지 진행됐는지 살펴볼 수 있도록.

필요하면 사용자가 작업을 바꾸고, AI와 다시 조정해. 캔버스는 단순한 과정 전시가 아니라 **사람과 AI가 같은 작업을 이해하는 공간**이야.

## 잘 만든 작업은 남겨

한 번 유용했던 작업을 매번 새로 설명할 필요는 없으니까.

작업을 재사용 가능한 스킬로 정의하고, 반복할 만한 흐름은 함수로 남겨 다음에는 새로운 입력과 조건에 집중하는 것. **작업이 끝나도 그 과정의 가치는 남도록** 만드는 게 오블의 중요한 목표야.

---

오블은 AI를 대신하는 또 하나의 지능을 만들려는 게 아니야. 이미 강력한 AI를 **더 쉽게 활용하고, 이해하고, 다시 활용할 수 있게** 하려는 거야.

모든 일을 자동화하거나 모든 판단을 AI에게 맡기는 것보다 중요한 건, **사용자가 원하는 결과에 더 적은 수고로 도달하고 필요할 때 주도권을 잡을 수 있는 경험.**

**대화가 일회성으로 끝나지 않는 곳. Ovll.**
