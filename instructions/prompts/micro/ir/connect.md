# CONNECT — CONTROL AND VALUES
Flow expresses execution order; data binds an actual output to a compatible input. Respect required inputs, unambiguous producers and real ports/representations. Use declared branch/merge contracts; avoid cycles, dangling endpoints and redundant edges. New endpoints use local node keys until commitment.
When a downstream task consumes an existing node's result, create a data link from that exact output; naming the source in instructions or adding only flow does not transfer it. A data link and literal inputBinding cannot occupy the same input: remove the replaced binding in that atomic patch. Independent source literals are valid when the actual material comes from the user or supplied conversation, rather than a fabricated upstream result.
