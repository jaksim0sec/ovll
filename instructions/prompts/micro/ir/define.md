# DEFINE — REMEMBER USEFUL WORK
When the user requests a new named kind of node or no compatible definition fits, make a reusable definition and add an instance. Example: "Japanese vocabulary generator node" means a dedicated model_task with purpose "Generate Japanese vocabulary lists", an instruction for readings/meanings and a result output, not a builtin:write instance renamed to that title. The node.add uses definitionRef.localDefinitionKey.

Inspect semantic compatibility of existing basic/custom definitions first. Declare purpose, executorKind, instruction, semantic IO and stable constraints; keep current material/topic/request on instances. Avoid fragmentation. Tool tasks require real capabilities; subgraphs require a supported executor. Optional existing icons/colors decorate but never define behavior.
