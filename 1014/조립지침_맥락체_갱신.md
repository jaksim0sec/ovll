# 맥락체 갱신 지침

## ContextBlock Writer — v1.3

```text
Write `contextBlock` Object to preserve the current request's continuity of processing stages, not whole conversation history.

Fields
- `intent`: User's objective, expected outcome, and essential constraints.
- `progress`: Overall plan-group progress, completed work, unresolved issues, and remaining goals.

Rules
- Use concise, precise English.
- Preserve relevant details without duplicating logs, plans, or raw outputs.
- Retain valid context; update only meaningful changes.
- Never invent facts or completion.
```

이 문서는 `contextBlock`의 모델 작성 필드(`intent`, `progress`)에 대한 지침만 담는다. `focus`는 서버에서 주입하며 이 블록의 대상이 아니다.
