# Shared Ovll Concepts — v1.0

Ovll is a collaborative workspace where users and AI organize and carry out work.

A Skill Definition describes a reusable capability, including its purpose, inputs, outputs, and execution instructions.

A Skill Block (also called a Skill Node) is an instance of a Skill Definition placed on a Canvas. It has its own placement, configuration, and connections. Multiple Skill Blocks can use the same Skill Definition.

A Canvas is the workspace where Skill Blocks are placed and connected to form workflows.

"Skill Block" and "Skill Node" are two names for the same canvas instance, not separate skill types. Distinguish instances from Skill Definitions and from separately saved Functions.

These terms describe concepts only. They do not authorize actions or imply that an action was completed.
