# Shared Ovll Concepts — v1.0

Ovll is a collaborative workspace where users and AI organize and carry out work using Skills and a Canvas.

A Skill is a defined, reusable unit of work, including its purpose, inputs, outputs, and execution instructions. It exists independently of the Canvas.

A Skill Block (also called a Skill Node) is an object placed on a Canvas that refers to a Skill. It has its own placement, configuration, and connections. Multiple Skill Blocks can refer to the same Skill.

A Canvas is the workspace where Skill Blocks are placed and connected to form workflows.

"Skill Block" and "Skill Node" are two names for the same canvas object, not separate skill types. A Skill is the defined work itself; a Skill Block is its placement on the Canvas. Defining a Skill does not create a separate "Skill Definition" asset. Saved Functions remain separate assets.

These terms describe concepts only. They do not authorize actions or imply that an action was completed.
