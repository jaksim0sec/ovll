# 맥락체 구조

## 정의

맥락체(Context Object)는 **현재 처리 중인 단일 사용자 요청의 응답 내부**에서 계층 간 의도와 진행 흐름을 이어주는 경량 매개체다.

세션 전체의 대화·작업 이력을 참조하는 **맥락데이터(Context Data)**와는 별개다. 맥락체는 세션 요약이나 상세 실행 로그 저장소가 아니다.

## 필드 구조

| 필드 | 기록 내용 | 작성·관리 |
|---|---|---|
| `intent` | 이번 요청의 의도, 목표, 기대 결과, 핵심 제약 | 맥락체 생성기가 작성·갱신 |
| `progress` | 현재 응답의 계획 묶음 단위 전반적인 진행 흐름, 주요 완료·미해결 사항, 남은 목표 | 맥락체 생성기가 작성·갱신 |
| `focus` | 직전 계층·작업의 관련 정보와 현재 호출의 계층·작업 위치 | 서버가 호출마다 교체 |

### 필드별 책임

- `intent`와 `progress`는 **맥락체 생성·갱신 기능이 작동할 때만** 변경된다. 각 작업실 실행 시 자동 재작성하지 않는다.
- `focus`는 **서버가 매 호출마다 구성하는 로그형 동적 필드**다. 이전 작업의 확인된 사실·필요한 참조와 현재 계층·작업을 간결하게 표현한다.
- **맥락체 생성기는 `focus`의 존재를 알지 못하며**, `intent`와 `progress` 두 필드만 다룬다.
- 원본 계획, 산출물, 상세 실행 로그와 실제 실행 상태는 별도로 관리하며 맥락체에 복제하지 않는다.

## 내부 표현 방식

- 영문 기반의 짧고 명확한 구문으로 기록한다.
- 목표·제약·진행 의미를 잃지 않는 범위에서만 축약한다.
- 길이 또는 토큰 수의 고정 최소·최대치를 두지 않는다.
- 대화 원문, 실행 결과 원문, 다른 입력에서 이미 제공되는 내용을 불필요하게 반복하지 않는다.
- 추측을 사실로 표현하거나 확인되지 않은 작업을 완료로 기록하지 않는다.
- `focus`에는 직전 작업과 현재 작업의 연결만 전달하며 특정 계층의 상세 지침을 중복하지 않는다.

## 형태 예시

맥락체 생성기가 작성하는 부분:

```json
{
  "intent": "Research topic and deliver a PDF report; retain source references",
  "progress": "Research complete; PDF generation pending"
}
```

서버가 현재 호출의 `focus`를 결합한 전달 형태:

```json
{
  "intent": "Research topic and deliver a PDF report; retain source references",
  "progress": "Research complete; PDF generation pending",
  "focus": "Previous: research completed, output ref=R12; current: createFile.generatePDF"
}
```

예시는 데이터 형식 설명이며 실행 사실을 의미하지 않는다.

> 이 문서는 맥락체의 **데이터 구조와 내부 표현 방식**만 정의한다. 맥락체 생성기 지침 문구와 모델 반환 JSON 전체의 조립 계약은 다루지 않는다.
