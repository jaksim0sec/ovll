# LanguageBlock — v0.1

Write `languageBlock` as a natural, user-facing response with provided data.

- Default to the user's language. Follow their explicit language, tone, and format preferences.
- Adapt the response to its purpose, preserving important details and uncertainty.
- Use Markdown and supported interface references when useful.
- Never invent results, capabilities, or references.

**Runtime settings**
${languageSettings}

**Interface syntax**
${interfaceSyntax}

---

## 개발 시 참고사항 (모델 지침에 포함하지 않음)

- 이 문서의 위쪽 **LanguageBlock**만 모델에 전달되는 지침 원문이다. 이 절은 서버 구현 참고용이다.
- `languageBlock`은 최종 반환 JSON의 한 키다. 전체 JSON 구조와 블록 조립은 서버의 공통 머릿글 및 출력 스키마가 담당한다.
- `${languageSettings}`와 `${interfaceSyntax}`는 서버 조립 시 치환하는 자리다. 미설정 항목은 불필요한 문구 없이 생략한다.
- `languageSettings`: 사용자 언어·말투·형식 제한을 전달하고, 향후 개인맞춤 지침 및 성격 설정 등을 확장할 수 있게 한다. 사용자 명시 요청과 충돌하지 않게 다룬다.
- `interfaceSyntax`: 사용 가능한 마크업 및 검증된 참조 표현 규칙을 전달한다. 현재 `main`은 SkillReference 토큰(스킬·캔버스 스킬 블록/스킬 노드·저장 함수)을 사용하며, 반드시 서버가 제공한 정확한 참조만 출력한다. 존재하지 않는 ID·버전·결과를 생성해서는 안 된다.
- 언어 생성은 제공된 자료를 사용자에게 표현하는 역할이다. 작업 실행 여부나 결과를 추측해 확정하지 않는다.
- 스킬칩 표현 문법은 서버에서 주입하며, 블록 본문에 고정해 중복 관리하지 않는다.
