# Corridor — 최초·회귀 호출 조립서

> 설계 기록 · 두 Corridor 베이스의 호출 구성과 반환 계약을 설명한다. 실제 서버 구현 완료를 의미하지 않는다.

## 1. 최초 복도 (Corridor Initial)

### 입력
- 현재 사용자 요청 원문
- Gate가 `need`로 추가 요청해 서버가 확보한 데이터

직접 응답 분기에서 `contextData`를 갱신하려면 **기존 맥락데이터**가 갱신 입력으로 제공되어야 한다. 이는 추가 정보 요청 블록을 복도에 붙인다는 뜻이 아니라 기존 세션 데이터의 서버 제공 조건이다.

### 지침 조립 순서
1. `공통지침_핵심개념.md`
2. `베이스지침_Corridor_Initial.md`
2. `공통지침_JSON_규칙.md`
4. `조립지침_언어_생성.md`
5. `조립지침_계획_생성.md`
6. `조립지침_맥락체_갱신.md`
7. `조립지침_맥락데이터_생성.md`

### 반환 — 두 가지 중 하나

**즉시 응답 가능:** 별도의 작업이나 실행 절차 없이 대답할 수 있는 경우

```json
{
  "languageBlock": "...",
  "contextBlock": {
    "intent": "...",
    "progress": "..."
  },
  "contextData": {
    "overallFlow": "...",
    "currentTopic": "...",
    "details": "..."
  }
}
```

- `contextBlock`은 **이번 요청을 즉시 마친 시점의 얕고 정확한 기록**이다.
- 별도의 Output 호출을 중복 수행하지 않는다.

**작업 필요:** 스킬 사용·수정이나 별도 절차가 필요한 경우

```json
{
  "plan": [],
  "contextBlock": {
    "intent": "...",
    "progress": "..."
  }
}
```

- `plan`은 기존 계획 생성 지침의 작업실 단위 배열이다. `[]`는 구조 표시용 자리이며 작업이 필요한 분기의 권장 빈 계획을 의미하지 않는다.
- `contextBlock`은 최초 요청 원문 없이 회귀해도 **전체 요청의 목적·핵심 제약·진행 및 남은 목표**를 유지할 만큼 충분히 구체적이어야 한다.
- 이 분기에서는 `languageBlock`과 `contextData`를 반환하지 않는다.

## 2. 회귀 복도 (Corridor Return)

### 입력
- 기존 맥락체 `contextBlock` (최초 요청의 전체 의도를 이어받음)
- 작업실 실행 결과, 실패·오류, 기타 현재 판단에 관련된 서버 제공 데이터

원문 요청을 매번 다시 제공하는 구조로 가정하지 않는다. `focus`는 서버가 현재 호출에 맞춰 교체한다.

### 지침 조립 순서
1. `공통지침_핵심개념.md`
2. `베이스지침_Corridor_Return.md`
2. `공통지침_JSON_규칙.md`
4. `조립지침_계획_생성.md`
5. `조립지침_맥락체_갱신.md`

### 반환 — 고정

```json
{
  "plan": [],
  "contextBlock": {
    "intent": "...",
    "progress": "..."
  }
}
```

- `plan`에는 **다음 미니 플랜 또는 종결을 나타내는 `terminate`**가 들어간다. 종결을 별도 최상위 키로 반환하지 않는다.
- `contextBlock`은 실제 결과에 따라 전체 목표를 유지하고 누적 진행 상태를 갱신한다.
- 회귀 복도에서는 `languageBlock`과 `contextData`를 반환하지 않는다.
- 작업 실패 시 실패 사실을 반영해 합리적인 재계획 또는 종결을 선택하고, 같은 실패를 근거 없이 되풀이하지 않는다.

## 3. 종결과 책임 경계

- **최초 복도 즉시 응답:** `languageBlock` + 얕은 최종 `contextBlock` + `contextData`로 이 요청을 마친다.
- **최초 또는 회귀 복도의 계획에 `terminate`:** 계획 흐름이 종결을 호출하고 **Output 계층**이 최종 언어 생성·맥락체 갱신·맥락데이터 갱신을 담당한다.
- **계획에 `terminate` 없음:** 계획된 작업실들이 끝나면 복도로 회귀한다. 실제 실패로 인한 회귀도 가능하다.

모델에 반환할 `contextBlock`은 `intent`와 `progress`만 포함하며, `focus`는 서버 작성 필드다. 각 블록의 세부 문법은 대응하는 조립 지침만이 정의한다.
