# Gate — 호출 조립서

> 설계 기록. 모델에 전달되는 Gate Base 지침 원문과 구분한다.

## 입력

- 맥락데이터 (`contextData`): 세션 전체 맥락
- 현재 사용자 요청 원문

## 지침 조립 순서

1. `공통지침_핵심개념.md` — 공통 개념 정의
2. `베이스지침_Gate.md` — Gate의 역할과 판단 범위
3. `공통지침_JSON_규칙.md` — 활성 지침 블록의 반환값을 단일 JSON으로 구성
4. `조립지침_데이터_요청.md` — 추가 정보 요청 배열 `need`의 문법

요청 원문과 맥락데이터는 모델 입력으로 제공한다. 위 순서는 **지침의 조립 순서**이며, 입력 데이터의 배치 위치까지 확정하지 않는다.

## 결과 및 제어

- 모델 출력: 데이터 요청 지침의 `need` 배열을 담은 단일 JSON 객체
- 추가 정보가 필요하지 않으면 `need: []`
- 서버는 요청된 정보를 조회해 최초 복도 사이클의 입력으로 전달한다.
- Gate는 계획 생성, 작업 실행, 최초 맥락체 생성을 수행하지 않는다. 최초 맥락체 생성과 계획 수립은 복도 측의 책임이다.

이 문서는 Gate 호출 구성을 설명한다. 개별 지침의 세부 규칙은 해당 `*_지침.md` 파일에서만 관리한다.
